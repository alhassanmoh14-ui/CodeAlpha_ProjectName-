## Project Overview

This project focuses on educating individuals about phishing attacks and how to protect themselves from online threats.

It explains how attackers use fraudulent emails, fake websites, text messages, and social engineering techniques to deceive victims.

The project includes a training presentation, realistic phishing examples, an interactive quiz, and a facilitator guide.

## Project Objectives

- Explain phishing attacks.
- Identify suspicious emails and fake websites.
- Understand social engineering techniques.
- Educate users about cybersecurity best practices.
- Test awareness through an interactive quiz.

## How to Run the Quiz

1. Download or clone this repository.
2. Open the quiz folder.
3. Double-click phishing_quiz.html.
4. Open it using a web browser.
5. Answer the questions and submit your answers.

No additional software installation is required to run the quiz.

## Ethical Considerations

This project is designed for educational purposes only.

It does not collect passwords, verification codes, or personal information. All phishing examples are fictional.

The project demonstrates how cybersecurity awareness can help people identify suspicious online activities and protect sensitive information.
